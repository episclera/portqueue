# SQLite driver

Zero services, one file. Perfect for single-node apps, CLIs, desktop/edge deployments,
and tests.

## Connect

```ts
import { PortQueue } from '@portqueue/core';
import { SqliteDriver } from '@portqueue/core/drivers/sqlite';

const pq = new PortQueue({ driver: new SqliteDriver({ file: './queue.db' }) });
await pq.init();
```

Every `addJob` / `createWorker` / schedule call works identically to Postgres.

## Capabilities & notes

- **Single-writer** engine. Claiming uses a safe locking/polling strategy rather than
  `SKIP LOCKED`; WAL mode is recommended for concurrency.
- No cross-process `LISTEN/NOTIFY`; workers poll (`pollIntervalMs`).
- Best as a **single-node** queue. For horizontal scale across machines, use
  [Postgres](./postgres.mdx).
- Transactional enqueue via `fromBetterSqlite3(db)` (or `fromNodeSqlite`).

:::tip Optimization
Enable WAL, keep `pollIntervalMs` modest (e.g. 500–1000ms), and turn on
[retention](../guides/retention.md) to keep the file small.
:::
