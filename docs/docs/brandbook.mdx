# Brandbook

PortQueue's dashboard and docs share one calm, muted visual system. The goal is a
content-first surface: a dominant neutral, a single desaturated green accent, one text
colour, and low-contrast semantic colours used **only where they carry meaning**.

All colours are exposed as CSS variables from a single source of truth — the design tokens
in [`@portqueue/ui`](https://github.com/episclera/portqueue) (`src/theme/tokens.ts`). The
dashboard reads them through its styled-components `ThemeProvider`; this docs site mirrors
them onto Docusaurus's Infima variables. Change a token once and both surfaces follow.

## Semantic palette

Muted and desaturated to match the core palette — **never** saturated/pure red, orange or
blue. Use them only when the context genuinely means it; never decoratively. Always pair
with `--text` (dark) for on-colour text, never white.

## Usage rules

- **Neutral dominates.** `--bg` covers the majority of every screen. `--primary` is an
  accent — buttons, active nav/tabs, links, positive indicators — never a big background.
- **One text colour.** `--text` (`#1B1F1D`) for everything; drop to ~60–75% opacity for
  secondary/muted text. No warm greys, no pure black, no white body text.
- **Contrast first.** Because the accents are light and muted, on-colour text is always the
  dark `--text`, not white — this keeps every combination at WCAG AA. Light green is used
  for *fills*; the darker `--primary-dark` is used for green *text/links* on light surfaces.
- **Semantics carry meaning.** `--danger`/`--warning`/`--info` appear only where they mean
  something — never for decoration.

### On the dashboard

`--primary` for KPIs, active filters, primary CTAs. `--danger` for negative deltas, failed
jobs, destructive actions. `--warning` for threshold alerts, pending states, stale-data
indicators. Tables and charts stay on `--bg`/`--surface` with `--secondary` gridlines so
semantic colours stand out only where they're meaningful.

### In these docs

`--bg` for content, `--secondary` for code blocks and dividers, `--primary` for links.
Admonitions always sit on a plain white (`--surface`) banner — **no coloured fill** — and only
the **title** takes a semantic colour: `--info` blue for `:::info`, `--warning` orange for
`:::warning`/`:::caution`, `--danger` red for `:::danger`. `:::note` stays neutral. Green is
never used for a banner.

:::info Info
Informational callouts use a blue title on a white banner.
:::

:::note Note
Plain asides use a neutral title — no accent colour.
:::

:::warning Warning
Caution/deprecation admonitions use the muted `--warning` orange title.
:::

:::danger Breaking change
Critical/breaking admonitions use the muted `--danger` red title.
:::
