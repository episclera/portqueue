# Installation

Install `@portqueue/core` plus the **client for your database** — the DB clients are
**optional peer dependencies**, never auto-installed, so you only pull in what you use.

<DriverTabs mode="install" />

Prefer another package manager? The install is identical apart from the command — the DB
client tracks the engine you picked above:

## Connect

Construction wires dependencies only — **no connection, no I/O**. `init()` connects,
migrates, and starts services. It is idempotent, so it's safe to await once.

<DriverTabs mode="connect" />

:::tip One API, any engine
Every `createQueue` / `addJob` / `createWorker` call below works identically no matter
which driver you constructed. Swapping engines is a one-line import change.
:::
