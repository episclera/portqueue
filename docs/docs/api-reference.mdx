# API Reference

Every public method and option in `@portqueue/core`, laid out as a hierarchy: each
**class** and **method** is a badge on its own line, and the options a method accepts are
nested underneath it. Object-shaped options link to their own section, where every field is
listed with its type and default. Durations accept a number of milliseconds or a human string
like `'30s'`, `'5m'`, `'1h'`.

<span className="api-badge is-class">class</span>&nbsp; <span className="api-badge is-method">method</span>&nbsp; <span className="api-badge is-options">options object →</span>&nbsp; <span className="api-badge is-opt">scalar option</span>

## Worker

A consumer registration from `pq.createWorker(options)`. It starts claiming automatically after
`pq.init()` and stops on shutdown — **there are no lifecycle methods**. Control processing through
the `Queue` (`pause`/`resume`) and observe it through `pq.on(...)`. All consumer settings live on
[WorkerOptions](#workeroptions).

## Options

### PortQueueOptions

The single argument to `new PortQueue(...)`.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `driver` | `Driver` | — **required** | A driver instance (see [Drivers](#drivers)). |
| `logger` | `Logger \| LoggerOptions` | console logger | A logger you supply, or `{ level?, pretty? }` for the built-in one. |
| `migration` | `MigrationMode` | `AUTO` | `AUTO` (apply pending on init), `MANUAL` (call `migrate()` yourself), or `VALIDATE_ONLY` (fail if pending). |
| `instance` | [`InstanceOptions`](#instanceoptions) | — | This process's identity & heartbeat. |
| `monitor` | [`SystemMonitorOptions`](#systemmonitoroptions) `\| false` | — | System-pressure thresholds; `false` disables sampling. |
| `tickIntervalMs` | `number` | `5000` | Scheduler / retention / monitor tick interval (ms). |

### ShutdownOptions

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `graceful` | `boolean` | `true` | Let in-flight handlers finish before disconnecting. |
| `timeoutMs` | `number` | `30000` | Max time to wait for a graceful drain. |
| `drain` | `boolean` | — | Keep claiming until the queue empties before stopping. |

### InstanceOptions

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `instanceKey` | `string` | anonymous | Stable, human-meaningful name for this process (e.g. `'worker-eu-1'`). Naming it lets you target, list, and pause it; unnamed processes still run jobs. |
| `heartbeatIntervalMs` | `number` | `15000` | How often the instance row's `last_seen_at` is refreshed (ms). |

### SystemMonitorOptions

Workers pause on pressure only when they opt in via `limiter.respectSystemPressure`. Pass
`monitor: false` to turn sampling off entirely.

| Option | Type | Description |
|--------|------|-------------|
| `sampleIntervalMs` | `number` | How often to sample system metrics (ms). |
| `maxEventLoopDelayMs` | `number` | Event-loop delay above this counts as pressure. |
| `maxCpuPercent` | `number` | CPU usage above this counts as pressure. |
| `maxMemoryPercent` | `number` | Memory usage above this counts as pressure. |
| `maxRssBytes` | `number` | RSS above this counts as pressure. |
| `resumeHysteresis` | `number` | Fraction (0–1) below the threshold metrics must fall to before resuming. |

### QueueOptions

The second argument to `createQueue`.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `defaultJobOptions` | [`JobOptions`](#joboptions) | — | Defaults every job on this queue inherits; a per-job option overrides. |
| `retention` | [`RetentionOptions`](#retentionoptions) | keep forever | Queue default retention; resolved per-job and frozen onto each row. |
| `hooks` | `HookRegistration[]` | `[]` | Queue-scoped [participation hooks](./events-hooks/hooks.md). |

### JobOptions

Per-job settings (highest precedence). Also the base of [`AddJobOptions`](#addjoboptions).

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `priority` | `number` | `0` | Higher runs first. |
| `retry` | [`RetryOptions`](#retryoptions) | run once | How the job retries on failure. |
| `expireIn` | `Duration` | — | Expire the job if it hasn't started within this window. |
| `retention` | [`RetentionOptions`](#retentionoptions) | inherit queue | Per-job retention override. |
| `idempotencyKey` | `string` | — | A second enqueue with the same key returns the existing job. |
| `singletonKey` | `string` | — | At most one active job per key at a time. |
| `tx` | `TransactionHandle` | — | Transactional enqueue: your own transaction, wrapped by an adapter. |

### AddJobOptions

`JobOptions` plus the fields below — the argument to `addJob`.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `data` | `TData` | — **required** | The job payload (a named key, never positional). |
| `schedule` | [`ScheduleOptions`](#scheduleoptions) | run now | One-off delay, fixed interval, or cron. |
| `startStep` | `string` | entry step | For a workflow queue: begin at a non-entry step (rare). |
| `preferredInstanceKeyPattern` | `string` | any | Regex source matching instance keys this job may run on. See [Scaling](./scale-horizontally.md). |

### RetryOptions

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `maxAttempts` | `number` | `1` | Total attempts including the first (`1` = no retry). |
| `delay` | `Duration` | — | Delay before a retry. |
| `backoff` | [`BackoffOptions`](#backoffoptions) | — | Backoff applied to `delay`. |

### BackoffOptions

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `strategy` | `BackoffStrategy` | — **required** | `FIXED` or `EXPONENTIAL`. |
| `factor` | `number` | `2` | Growth factor for `EXPONENTIAL`; ignored for `FIXED`. |
| `maxDelay` | `Duration` | — | Cap on the computed delay. |
| `jitter` | `boolean` | `false` | Randomize the delay to spread retries across instances. |

### RetentionOptions

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `mode` | `RetentionMode` | — **required** | `KEEP_FOREVER` or `DELETE_AFTER`. |
| `ttl` | `Duration` | — | How long after finishing before deletion is allowed (required for `DELETE_AFTER`). |
| `statuses` | `JobStatus[]` | `[COMPLETED]` | Which finished statuses the policy applies to. |

### ScheduleOptions

Exactly one timing mode may be set.

| Option | Type | Description |
|--------|------|-------------|
| `startAfter` | `Date \| Duration` | One-off: run not before this time. |
| `startEvery` | `Duration` | Recurring: a fixed interval between runs, e.g. `'30s'`. |
| `cron` | `CronSpec` | Recurring: a cron string, or `{ pattern, tz }`. |

### WorkerOptions

The argument to `createWorker`.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `queue` | `TQueues` | — **required** | The queue this worker claims from. |
| `handler` | `JobHandler \| WorkflowStep[]` | — **required** | A single processor function (simple mode) or an ordered array of steps (workflow mode). |
| `limiter` | [`LimiterOptions`](#limiteroptions) | defaults | Throughput & claim tuning. |
| `dontAutoretryFor` | `Array<ErrorClass \| string>` | `[]` | Non-retryable errors, matched by `instanceof` or `error.name`. |

### LimiterOptions

All **worker-local** — no cluster-wide coordination.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `concurrency` | `number` | `1` | Max handlers running at once in this worker. |
| `rateMax` | `number` | — | Max jobs started per `rateDuration` window (set with `rateDuration`). |
| `rateDuration` | `Duration` | — | The window for `rateMax`, e.g. `'1m'`. |
| `respectSystemPressure` | `boolean` | `false` | Pause claiming while system pressure is high. |
| `batchSize` | `number` | `concurrency` | Max jobs claimed per fetch. |
| `pollIntervalMs` | `number` | `5000` | Poll cadence when `LISTEN`/`NOTIFY` is unavailable (ms). |
| `lockDurationMs` | `number` | `30000` | Visibility timeout / heartbeat window for a claimed job (ms). |

### GetJobsQuery

| Option | Type | Description |
|--------|------|-------------|
| `queue` | `string` | Filter to one queue (implicit on `Queue.getJobs`). |
| `statuses` | `JobStatus[]` | Filter by status. |
| `scheduleId` | `string` | Jobs minted by one schedule. |
| `workflowId` | `string` | Jobs in one workflow run. |
| `limit` | `number` | Page size. |
| `cursor` | `string` | Opaque cursor from the previous page. |
| `order` | `'asc' \| 'desc'` | Sort direction. |

## Result types

Reads return objects, never bare ids. The main shapes:

- **AddJobResult** — `jobId?`, `scheduleId?`, `nextRunAt?`, `queue`, `status?`, `deduplicated`, `deduplicationReason?`, `startAfter?`, `workflowId?`.
- **JobSnapshot** — the full read-side view of a job (all timestamps as `Date`, plus a derived `stalled` flag).
- **WorkflowSnapshot** — `workflowId`, `queue`, `steps: JobSnapshot[]`.
- **ScheduleInfo** — `scheduleId`, `cron?`, `every?`, `timezone?`, `nextRunAt?`, `lastRunAt?`, `enabled`, `idempotencyKey?`.
- **QueueInfo** — `name`, `processingPaused`, `acceptingPaused`, `counts`, `inUse`.
- **InstanceInfo** — `instanceKey`, `processingPaused`, `alive`, `createdAt`, `updatedAt`, `lastSeenAt`, `counts`.
- **QueueStats** — `queue?`, `counts`, `throughputPerMinute`, `failureRate`.
- **Page&lt;T&gt;** — `items`, `cursor`, `hasMore`.
